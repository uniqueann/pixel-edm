# 模板库与模板编辑器：评审前三项实施与验收

日期：2026-10-30。分支：`design/templates-editor-polish`。基线：`main` 的 `ba4e9aa`。

本轮沿用 impeccable 评审快照 `2026-10-29T12-16-34Z__src-features-templates-templates-tsx.md`，按 **harden → clarify → layout/adapt → polish** 实施前三项。模板是后续活动的内容来源；较长的英文正文需要连续写作，离开丢稿风险与预览保存边界应优先处理。

## 前后对照

| 环节 | 修改前 | 修改后 |
| --- | --- | --- |
| 从编辑器进入设置 | 预览内三类配置链接直接导航 | 发信通道、店铺信息、真实署名链接共用未保存确认；可继续编辑或放弃后离开 |
| 取消、关闭、Esc | 已有关闭确认 | 保留原确认；取消导航后清除待执行跳转，后续关闭不会误导航 |
| 刷新与关页 | 无模板专用提醒 | 模板字段变化期间注册 `beforeunload`；关闭编辑器或保存完成后移除 |
| 示例值保存范围 | 编辑内七项示例输入位于保存表单中，说明不足 | 示例输入移到表单外；两个预览入口共用“不保存到模板”的说明 |
| 变量含义 | 将替换值泛称为客户资料，“发件人”与 From 易混 | 分为客户资料、活动统一信息；`sender_name` 显示为“正文署名”，真实 From 保留独立名称 |
| 邮件核对 | 默认展示全部七项示例，再展示邮件 | 默认折叠示例控制，优先展示模板实际使用的变量；姓名的备用邮箱保留在相邻字段，其余项可展开 |
| 桌面布局 | 740px 单列，邮件与保存操作位于长表单后 | 最大 1120px，960px 起编辑／预览并列；一个中段滚动区，操作栏独立于滚动内容 |
| 手机与中等宽度 | 字段、示例、邮件与按钮纵向堆叠 | 编辑／预览明确切换；切换保留模板和示例输入，保存先显示编辑字段再做原生必填校验 |
| 保存失败 | 错误提示随长表单滚动 | 错误出现在可见的底部操作区，输入保留，可再次保存 |

改前对照依据 `ba4e9aa` 源码；改后截图来自本地仓库回归。旧编辑器没有同场景截图，不将结构对照当作改前浏览器实拍。

## 实现与业务边界

- `use-unsaved-edit-dialog.tsx` 增加主动离开入口，复用现有确认弹窗；现有客户、活动编辑器的关闭调用保持兼容。
- `email-outbound-preview.tsx` 增加可选的设置导航回调。模板编辑器接入保护，独立预览及其他调用沿用原导航方式。
- 设置链接使用 Next.js `Link.onNavigate`；当前页导航可以被确认流程接管，新标签页操作保留链接原生行为。
- 模板脏状态仍只比较名称、分类、主题、正文。预览示例仅保存在当前组件内，退出后重新使用默认示例。
- `saveTemplate` 的提交字段、版本校验、权限、配额、归档恢复、变量替换与复制文本规则保持原实现。没有服务端接口、数据库迁移或计费改动。
- 编辑器中段使用独立焦点可见性处理与 `ResizeObserver`，配合现有 Dialog 的可视视口变量；保存栏占据正常布局空间。
- 正文、长链接、真实 From 和错误文本支持断行；输入、切换、保存及变量按钮采用至少 44px 的操作高度，沿用暖灰／深蓝与明暗主题变量。

## 回归验收

仓库新增四条编辑器 E2E，使用 `templates@example.test` 独立测试账号与工作区，避免其他设置测试保存署名后污染缺省场景。认证使用本地夹具，业务数据仍经过本地 PostgreSQL RLS。通道凭据是夹具值，没有发送实际邮件。

| 验收路径 | 预期与证据 |
| --- | --- |
| 修改模板 → 三类设置链接 → 继续编辑／Esc | 保持模板 URL 和输入内容 |
| 取消过导航 → 普通取消 | 仅显示关闭确认，未残留设置跳转 |
| 放弃并离开 | 前往设置，未创建未保存模板 |
| 未修改模板／独立预览 → 设置 | 直接前往设置，不出现丢稿确认 |
| 修改后刷新 → 取消原生提示 | 浏览器出现 `beforeunload` 提示，模板输入仍在 |
| 修改预览客户名、优惠和署名 → 保存 → 重开 | 保存的主题、正文仍含原始变量；预览示例回到默认值 |
| 仅修改预览示例 → 取消 | 不进入模板脏状态，不触发放弃确认 |
| 手机预览侧保存空模板 | 先返回编辑内容，聚焦模板名称 |
| 保存请求失败 → 重试 | 可见错误提示，原正文保留；取消故障后保存成功 |
| 1440／820／390／320px 与长正文、长链接 | 结构按断点切换，无弹窗或内容横向溢出；滚动前后操作栏位置稳定 |
| 手机可视高度收缩至 420px | 焦点示例字段处于中段可见范围，保存栏位于可视视口内 |
| 关闭编辑器 | 焦点返回“新建模板”入口 |
| 明暗主题 | 邮件正文和预览说明对比度均达到 4.5:1；结果随 E2E 作为 `contrast.json` 附件输出 |
