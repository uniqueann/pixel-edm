# P12 支付商品文案（Creem / Dodo 粘贴用）

更新日期：2026-09-21。商品名称保持 **`Pixel EDM Pro Monthly`** / **`Pixel EDM Pro Yearly`**（USD 9.90/月、99.90/年不变）。仓库内无 Creem/Dodo 改商品描述的 API，请在各 Dashboard **Products** 中手工更新下列字段。

## 专业版 · 月付 / 年付（共用描述）

### 中文（建议作为 Description / 副标题）

个人专业版：最多 **5,000** 位有效客户（未归档）；自定义模板与每月活动确认不限；**打开/点击统计**；**近 7 日操作日志**；**单人**使用（不含团队成员邀请）。更大名单或协作请升级 **团队版**。不按发信量对价；平台日发信护栏仅作公平与滥用防护。

### English

Pixel EDM Pro: up to **5,000** active contacts (non-archived); unlimited custom templates and confirmed campaigns per month; **open/click analytics**; **7-day activity log**; **single-seat** workspace (no team invites). Need more contacts or collaboration? Upgrade to **Team**. Pricing is not send-volume based; daily send caps are platform safeguards only.

## 团队版 · 月付 / 年付（共用描述）

商品名建议：**Pixel EDM Team Monthly** / **Pixel EDM Team Yearly**（USD 29.90/月、299.90/年，见 `development-checklist-p11-billing.md`）。

### 中文

团队版：最多 **25,000** 位有效客户；**20 个团队席位**与成员邀请（管理员/运营/查看者）；**完整操作日志**；含专业版全部发信、模板、活动确认与打开/点击统计。更大名单或额外席位后续通过加购包扩展。不按发信量对价。

### English

Pixel EDM Team: up to **25,000** active contacts; **20 seats** with invitations and roles (admin/editor/viewer); **full activity log**; includes all Pro sending, templates, campaigns, and analytics. Larger lists or extra seats via add-ons (coming soon). Not priced by send volume.

## Dashboard 操作清单

1. **Creem** → Products → EDM **Pro + Team** 各月付、年付 → 粘贴对应中/英描述 → 保存。
2. **Dodo** → 测试与正式环境各 **4** 个 EDM 商品（Pro/Team × 月/年）→ 同上；Team 接入步骤见 `docs/p11-team-billing-setup.md`。
3. 改完后从设置页走 Pro / Team 测试 Checkout，确认结账页展示与上述一致（部分通道仅显示商品名，以 Dashboard 预览为准）。
