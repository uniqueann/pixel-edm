# 客户导入完整流程 UI / UX 打磨与验收

日期：2026-10-30。基线：`origin/main` 的 `8b1828a`。开发分支：`design/contact-import-polish`。

## 范围与证据口径

主流程：客户名单入口 → 提供名单 → 授权信息 → 预检 → 确认导入 → 分批处理／中断续导 → 结果／报告 → 客户名单。

仅调整导入前端、展示统计及测试。沿用暖灰／深蓝、现有字体、主题变量和共享 Button、Card、ConfirmDialog、ListPagination。客户名单已有导入入口可用，本轮不改其列表或权限行为。

交互浏览器实际返回 `Local browser use is disabled in Work settings`。没有通过其他交互通道绕过限制，没有注入 Impeccable overlay，也没有启动 live-server。本轮运行用户明确授权的仓库 Playwright 回归，使用本地隔离认证夹具、PGlite 和真实项目迁移／RPC；不连接生产数据库。

本文截图是本地 Chrome 自动化的受控场景。320／390／820／1440px 是模拟视口；可视视口收缩和 CSS 200% 放大也是模拟检查，不是真机、真实软键盘、人工交互浏览器、真实读屏或线上验收。

### harden：状态边界与恢复

- 未预检输入仅保存在当前页面内存，不新增本地持久化。离开站内链接或历史任务时复用现有未保存确认；刷新／关页使用原生卸载保护。
- 后退采用渐进增强：支持 Navigation API 且事件可取消时，在同源 traverse 提交前拦截；保留 popstate／beforeunload 回退。不会声称能够阻止浏览器强制离开或所有旧版浏览器导航。平台语义依据 [Navigation API 提案](https://github.com/WICG/navigation-api/blob/main/README.md)。
- 离开豁免在新一轮编辑／处理开始时复位，覆盖同页确认离开后继续编辑的路径。
- 文件读取、预检、确认／处理、翻页、载入历史和下载互斥。处理中禁止新建、切换输入方式、翻页或载入历史；页面卸载后停止继续批处理，不将迟到结果应用到其他任务／工作区。
- 同一任务的服务端刷新不重新挂载导入组件，防止 `revalidatePath` 清空互斥状态。工作区变化仍通过组件 key 隔离，显式选择不同任务或页码时同步正确结果。
- 中断不自动重试。继续或重试原任务前先只读查询当前状态，再处理原任务剩余记录；确认响应丢失也不会新建任务或盲目再次确认。
- 预检、分页、报告及文件失败提供持久错误和手动恢复；错误定位失败保留定位意图。切换至粘贴会清理文件失败状态并恢复自动分隔符，避免隐藏的 CSV 分隔符干扰 TSV。
- 取消授权声明后，已经填写的授权字段仍可见、可修改或清空，原有提交语义不变。

### clarify：统计与订阅语义

- 源数据行、格式有效的不同邮箱数、实际处理记录分开说明；错误记录单独保留，三个数字不要求相等。
- `countDedupedValidEmails` 只用于展示，改为按规范化邮箱去重，防止相同有效邮箱的多条字段错误重复计数。没有改动解析、归并或验证规则。
- 多页统计使用原有导出接口读取完整记录；读取失败时显示“暂不可用”，不根据当前页推算。
- “跳过或保留”包含无变化、归档跳过及保留防打扰状态；受保护客户的资料仍可能按既有规则补全，不能笼统称为全部跳过。
- 批量声明只为未填写状态的行设置默认值，CSV 逐行状态优先。CSV 提供授权列时，逐行空值也不会由批量值回填；已订阅行仍须通过既有证据校验。
- 下表展示的是本次请求的导入状态，最终订阅状态到客户名单核对。未确认不意味着现有订阅客户会降级；退订、投诉、硬退信与归档保护仍生效。
- 完成表示名单处理结束，包含错误和跳过；不显示无法可靠推算的可发信人数。报告继续使用既有导出字段，预检中待处理记录仍按原接口导出，不伪造最终处理结果。

### layout/adapt 与 polish

- 桌面将名单与授权并列；手机顺序阅读，操作栏自然滚动，避免固定底栏覆盖输入区域。
- 处理摘要后直接提供下一步操作，50 条结果不再迫使用户先滚到表格底部才能确认或返回修改。
- 小屏记录优先显示邮箱、处理结果、原因；长邮箱、文件名、标签与说明允许换行；保留语义表格与来源行。
- 多页复用共享分页，支持定位首个错误所在页；单页不显示无意义的禁用分页。
- 最近导入即时反映本次任务状态，区分待确认、待继续和完成；待确认不把已判错计数称作已导入。
- 控件与主要入口至少 44px，输入文字 16px；真实标题、选中状态、字段描述关系、结果焦点及适度状态播报齐全。
- 新增样式限定在导入 CSS module，不修改全局主题或共享控件行为。

## 业务兼容性

| 边界                             | 保持方式                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------- |
| 解析格式、列别名、大小与行数上限 | `import-parser.ts` 原样保留；仍为 2 MiB／1000 行                                 |

| 依赖与全站组件                   | 不新增包，不改全局主题、共享组件和其他页面业务                                   |
